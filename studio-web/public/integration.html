Produção por comandos

No navegador do assistente

Em ambientes compatíveis com WebMCP, abrir o estúdio disponibiliza ferramentas para ler a sessão, editar uma pista, salvar um marco e reproduzir uma prévia. Funciona na sessão aberta e não exige copiar credenciais. Em navegadores comuns, os controles continuam funcionando normalmente.

MCP remoto / API

Endpoint: https://ai-music-studio-tiagolif.vercel.app/api/mcp

Transporte: Streamable HTTP stateless, respostas JSON. Requer Authorization: Bearer <JWT de usuário Supabase>. A sessão expira e precisa ser renovada pelo cliente. OAuth específico para conectar no ChatGPT ainda não está implementado; publicar este endpoint não instala a integração automaticamente.

API REST: POST /api/studio, com o mesmo cabeçalho. Operações: list_projects, create_project, get_project, save_project, apply_command, save_version, list_versions, restore_version e render_project.

Exemplo: trocar somente o kick

{
  "action": "apply_command",
  "id": "UUID do projeto",
  "revision": 1,
  "command": {
    "action": "replace_instrument",
    "trackId": "track-0",
    "preset": "punch"
  }
}

Leia a revisão com get_project antes de escrever. Uma revisão antiga retorna conflito. Pistas aprovadas precisam ser desbloqueadas explicitamente. O motor não gera voz cantada nem interpreta linguagem natural por conta própria: o assistente transforma o pedido em operações.

Áudio e biblioteca

Presets sintetizados próprios de kick, clap, hats, baixo e synth. Samples importados são convertidos para WAV mono PCM 16-bit 44.1 kHz ao salvar na nuvem. A mixagem sai em WAV estéreo 44.1 kHz 16-bit, com proteção de pico; a análise mostra pico e RMS, não LUFS.

A renderização remota lê o projeto privado, produz o áudio e armazena um arquivo privado. Retorna um link válido por uma hora. Limite do arranjo: 64 compassos. Não há fila durável: se uma requisição falhar, é necessário repetir a renderização.
